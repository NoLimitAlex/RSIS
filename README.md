# RSIS

Website of the Ressu Student Investment Society, a student-led investment society at Ressu upper secondary school in Helsinki.

## About the site

- A single static page: everything is in `index.html`. There is no build step and nothing to install.
- Open `index.html` in a browser to view it, or serve the folder with any static host.
- Fonts (Fraunces and IBM Plex Mono) load from Google Fonts, with system fallbacks when offline.
- The background lines are generated in the browser. They are decorative and are not market data.
